# Third-party data and components

Stratavox code is covered by `LICENSE`. The data and components below belong to their providers and keep their own terms.

| Provider | Used for | Terms |
|---|---|---|
| Open-Meteo | Forecast models, air quality, geocoding | CC BY 4.0; free tier is for non-commercial use |
| National meteorological services via Open-Meteo (ECMWF, NOAA, DWD, ECCC, Meteo-France, JMA, UK Met Office, CMA, KNMI, DMI, MET Norway, MeteoSwiss, ItaliaMeteo) | Model data | Open data licenses of each service, attribution required |
| MET Norway Locationforecast | Forecast | NLOD 2.0 / CC BY 4.0 |
| US National Weather Service API | Forecast, station observations, alerts | US public domain |
| Deutscher Wetterdienst via Bright Sky | Station observations, alerts (Germany) | DWD open data terms, attribution required |
| World Weather Online via wttr.in | Forecast and current conditions | Provider terms apply |
| Copernicus Atmosphere Monitoring Service | Air quality | Copernicus licence, attribution required |
| GeoNames via Open-Meteo geocoding | Place search | CC BY 4.0 |
| BigDataCloud | Reverse geocoding | Provider terms apply |
| NOAA MRMS via the NCEP GeoServer (opengeo.ncep.noaa.gov) | US radar mosaics: base and composite reflectivity, precipitation type, echo tops | US public domain |
| NOAA map services (mapservices.weather.noaa.gov), Storm Prediction Center, National Hurricane Center | Storm outlook and tropical cyclone map overlays | US public domain |
| Iowa Environmental Mesonet, Iowa State University | NEXRAD mosaic tiles, MRMS rain totals | Open service, attribution requested |
| Environment and Climate Change Canada, MSC GeoMet | North American radar and extrapolation, GDPS model maps, lightning density, wildfire smoke | Environment and Climate Change Canada Data Servers End-use Licence, attribution required |
| Deutscher Wetterdienst GeoServer (maps.dwd.de) | Germany radar and radar forecast | DWD open data terms, attribution required |
| Japan Meteorological Agency | Japan radar nowcast tiles | JMA website terms of use, attribution required |
| RainViewer | Worldwide radar mosaic | Free API for personal and small projects, attribution required; check current limits |
| NASA GIBS / EOSDIS | GOES and Himawari satellite imagery, IMERG rain rate | Free and open, acknowledgement requested |
| EUMETSAT (view.eumetsat.int) | Meteosat satellite imagery, H SAF rain rate, lightning flash area | EUMETSAT data policy, attribution required |
| Esri (ArcGIS Online basemap tiles), with HERE, Garmin, Maxar, Earthstar Geographics, OpenStreetMap contributors | Base maps and place labels | Esri terms of use, attribution required; a commercial launch needs an ArcGIS account or another base map |
| Leaflet 1.9.4 (bundled in `vendor/`) | Map rendering | BSD 2-Clause, see `vendor/LEAFLET-LICENSE` |
| Bricolage Grotesque, Instrument Sans, IBM Plex Mono (Google Fonts) | Typography | SIL Open Font License 1.1 |

Check each provider's current terms before any commercial use.
