Stratavox code is covered by `LICENSE`. The data and components below belong to their providers and keep their own terms.

| Provider | Used for | Terms |
|---|---|---|
| Open-Meteo | Forecast models, air quality, geocoding | CC BY 4.0; free tier is for non-commercial use |
| National meteorological services via Open-Meteo (ECMWF, NOAA, DWD, ECCC, Meteo-France, JMA, UK Met Office, CMA, KNMI, DMI, MET Norway, MeteoSwiss, ItaliaMeteo) | Model data | Open data licenses of each service, attribution required |
| MET Norway Locationforecast | Forecast | NLOD 2.0 / CC BY 4.0 |
| US National Weather Service API | Forecast, station observations, alerts | US public domain |
| Deutscher Wetterdienst via Bright Sky | Station observations, alerts (Germany) | DWD open data terms, attribution required |
| World Weather Online via wttr.in | Forecast and current conditions | Provider terms apply |
| Copernicus Atmosphere Monitoring Service | Air quality | Copernicus licence, attribution required |
| GeoNames via Open-Meteo geocoding | Place search | CC BY 4.0 |
| BigDataCloud | Reverse geocoding | Provider terms apply |
| Bricolage Grotesque, Instrument Sans, IBM Plex Mono (Google Fonts) | Typography | SIL Open Font License 1.1 |

Check each provider's current terms before any commercial use.
